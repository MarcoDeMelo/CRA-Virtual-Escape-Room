# CRA Virtual Escape Room

An interactive virtual escape room developed as a web-based game using TypeScript, Phaser, and Vue.js.

## Live Demo

[Play the CRA Virtual Escape Room](https://craescaperoom.web.app/)

## Overview

The CRA Virtual Escape Room is an interactive browser-based experience designed around solving puzzles and progressing through an escape-room environment.

The project was developed as part of an internship project and involved building an interactive game experience for the Canada Revenue Agency.

## Technologies

* TypeScript
* Phaser
* Vue.js
* HTML
* CSS

## Features

* Interactive browser-based escape room
* Puzzle-based gameplay
* Interactive game objects
* User interaction and input handling
* Multiple game elements and scenes
* Web-based deployment
